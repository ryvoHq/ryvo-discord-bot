# Getting started with the RYVO Terminal
**Open the beta:** https://ryvohq.github.io/ryvo-terminal/
It runs in the browser on desktop and phone. You can also install it like an app from the browser.

**What's in it:** charts with orderflow tools, derivatives data (funding, open interest), news headlines, a market brief, macro data and memecoin tools in one place.

**Questions?** Open a post in this forum, one question per post. Add a screenshot and say which device and browser you use.

The beta is free and still changing. Data can be delayed or wrong. It is a data tool, not advice.
