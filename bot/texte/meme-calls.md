# How to post a call
One call per message. Use this format, or the message gets removed:

```
Coin:      $TICKER
Chain:     Solana / Base / ETH / ...
CA:        contract address
Why:       your reasoning in 1–3 lines
Plan:      entry area · where you are wrong · where you take profit
Position:  I hold it / I don't hold it
```

---
# Before you buy anything
· Check holder concentration, dev wallet and liquidity lock. Ask in {kanal:rug-check}.
· Size small. Assume any new coin can go to zero.
· Calls here are members' opinions, not advice. Coordinated buying or selling ("everyone buy at …") is forbidden.
